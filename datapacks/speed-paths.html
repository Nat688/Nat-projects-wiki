Speed Paths

Gain a configurable Speed effect while walking on Dirt Paths and the blocks of your choice, making roads faster and more rewarding to build.

Type Datapack / Mod
Version 1.21.9 - 26.3
Status Released

About

Speed Paths is a datapack that grants players a configurable Speed effect whenever they walk on Dirt Path blocks, making roads a valuable part of survival gameplay.

Whether you're connecting villages, your base or important locations, Speed Paths rewards players for building proper road networks by making travel significantly faster. Prefer gravel roads, sandstone streets or concrete highways? You can choose exactly which blocks give the boost.

Everything is fully configurable through built-in commands, a chat menu and a dialog window, allowing you to choose the Speed level and the blocks that best fit your world without editing any files.

Features

Speed Boost

Automatically gain a Speed effect while walking on Dirt Path blocks or any other block you enable.

Choose Your Blocks

Pick which blocks give speed: Path, Gravel, Sand and Sandstone, Stairs, Packed Mud, Slabs, Planks, Stone, Concrete and Terracotta.

Chat Menu and Dialog

Configure the blocks from a clickable chat menu or from a dialog window with checkboxes that show the current state.

Mount Support

Riding a horse or any other mount? The mount receives the Speed boost while it runs over a fast block.

Fully Configurable

Choose any Speed level from I to V directly in-game. New players start at Speed II.

Vanilla Friendly

Encourages road building without changing Minecraft's natural progression.

FAQ

Can I change the speed level?

Yes. You can choose any level between Speed I and Speed V using the built-in commands. Each player starts at Speed II the first time, and a /reload never resets it.

Which blocks give speed?

Only Dirt Paths by default. You can enable Gravel, Sand and Sandstone, Stairs, Packed Mud, Slabs, Planks, Stone, Concrete and Terracotta from the block menu (/function speed_paths:menu_blocks or /function speed_paths:dialog_blocks).

Is the block selection different for each player?

No. The block selection is global and applies to everyone, while the Speed level is chosen by each player.

Does it work when riding a horse?

Yes. The mount you are riding receives the Speed boost while it runs over a fast block.

Does it work on servers?

Yes. Speed Paths works in both singleplayer and multiplayer worlds.

Does it require a resource pack?

No. The datapack works without any resource pack.

Can I disable it?

Yes. Simply use the disable command or reset the speed level whenever you want.
