Cleric Heal Villager

A lightweight datapack that allows cleric villagers to automatically heal nearby villagers, making villages feel more alive while keeping the vanilla experience intact.

Type Datapack / Mod
Version 1.21.9 - 26.3
Status Released

About

Cleric Heal Villager is a lightweight datapack that allows cleric villagers to automatically repair nearby Villagers, helping them continue protecting villagers without requiring player intervention.

Features

Automatic Healing

Cleric villagers periodically restore the health of nearby Villagers.

Vanilla Friendly

Fits naturally into Minecraft without changing its progression or gameplay.

Lightweight

No configuration, no commands and almost no performance impact.

Multiplayer Compatible

Works in both singleplayer and multiplayer worlds.

Commands

No commands for users.

No commands for admins.

Installation

1. Download the datapack.
2. Place it inside your world's datapacks folder.
3. Run /reload or restart the world.
4. Have fun!

FAQ

Does this replace vanilla mechanics?

No. The datapack only adds automatic healing behavior while keeping vanilla gameplay unchanged.

Does it work on servers?

Yes. It works in both singleplayer and multiplayer worlds.

Does it require a resource pack?

No. The datapack works without any resource pack.
